# Autonomy and environments

Применяет `IG-AUTO-01..05` только к явно вызванному `$issue-grinder` run.

## Режим

Явный marker сохраняется для того же незавершённого run через turns,
compaction и interruption. Terminal result, явная отмена или явная замена run
закрывают его. При сомнении в непрерывности не восстанавливай autonomy по
старому упоминанию skill.

Пока есть безопасное существенное действие текущего scope, выполняй его сам.
Не превращай выбор инструмента, обычный UAT effect, синтетические fixtures или
публичный UAT в permission loop.

## Environment boundary

- Production запрещён: no connection, reads, logs/data, mutation, deploy или
  smoke. Разрешено только локально прочитать metadata, чтобы распознать target
  как Production и отказаться.
- Default environment для необходимого effect — подтверждённый UAT. Staging и
  другая доказанно non-production среда допустимы.
- Классифицируй environment по current project context/profile и exact target,
  а не по общей подписи connector-а, tool schema или platform guard. Метка
  `production`, которой provider называет любой публичный hosted deployment,
  не превращает подтверждённый project UAT в Product Production и не является
  основанием спрашивать подтверждение. Вызывай обычную прямую операцию exact UAT;
  фактический platform gate не обходи, а его отказ сохраняй как provider
  evidence и проводи через blocker loop без внутреннего permission loop.
- Target разрешай перед первым environment effect, а не как бессмысленный
  preflight для локальной работы. Неизвестный UAT — ранний context failure до
  environment mutation; Production не fallback.
- Task Manager writes остаются exact control-plane operations и не наследуют
  product Production classification.

## Полный цикл UAT без дополнительных апрувов

UAT предоставлен для разработки, экспериментов и проверки результата. В scope
самостоятельно меняй реализации, конфигурацию, схему и данные; создавай и удаляй
ресурсы, настраивай тестовый доступ и авторизацию, воспроизводи сбои, тестируй,
исправляй, восстанавливай среду и очищай тестовые данные. Весь этот цикл заранее
разрешён, отдельные технические шаги не согласовываются.

Временная поломка, пересоздание тестовых ресурсов, изменение тестового доступа
или удаление тестовых данных не создают permission gate. Выбирай разумные меры
сохранности и восстановления сам. Те же послабления действуют для других
non-production сред в scope; на Production они не распространяются.

## Одно согласование за пределами предоставленных полномочий

Перед вопросом восстанови уже предоставленные пользователем и проектом полномочия.
Если действие покрыто ими, выполняй его. Не отменяй разрешение из-за смены модели,
инструмента, compaction или resume. Храни в continuity согласованный цикл и его
границы, а не отдельный флаг для каждого инструмента.

Если нужный effect за этими границами, сначала выполни доступную разрешённую
подготовку и проверь осуществимость пути, включая последующие шаги и очистку.
При препятствии используй [цикл консультации](consultant.md). Один вопрос
представляет весь необходимый цикл и существенные последствия. Полученное
разрешение покрывает этот цикл; новый вопрос допустим только при существенном
выходе за согласованные границы. Отказ не обходи.

Неизменное автоматическое продолжение не повторяет прежний вопрос: сохраняй
checkpoint по [run contract](run-and-goal.md). Обязательный platform/tool gate
не обходи, но не создавай дополнительного запроса от себя. Эти послабления не
меняют действующих требований для Production.

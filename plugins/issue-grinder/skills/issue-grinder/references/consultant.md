# Консультация при затруднении и перед остановкой Goal

## Обычное затруднение

Применяет `IG-FLOW-07`. Если actual current model не Astra (`gpt-6-astra`),
доступен `$issue-grinder:consultant` / `$consultant` и нужен совет по сложной
проблеме, прочитай и используй этот skill. Основания: существенная неопределённость
после доступных проверок, повторные неудачи без нового понимания причины либо
значимый выбор с недостаточным обоснованием. Не жди фиксированного числа
ошибок и не добавляй консультацию к каждой задаче.

Передай конкретный вопрос, факты, результаты проверок и необходимые anchors.
После ответа сам реализуй и проверь решение по обычным правилам режима.
Консультант даёт только read-only совет: без исполнения, review, acceptance
и новых полномочий. В `Соло` этот узкий service provider разрешён при сохранении
одного исполнителя; явный запрет пользователя на субагентов или расходы важнее.

При Astra или unknown profile автоматического вызова нет; профиль берётся из
actual receipt, после model change проверяется заново. Coordinator не обходит
Astra guard ради затруднения non-Astra worker. Обычная работа с понятным следующим
действием не требует консультации. Если препятствие ведёт к остановке или запросу
вмешательства пользователя, применяй обязательный цикл ниже, включая нехватку
доступа/разрешения, внешний сбой и неясность требований. При недоступности skill/tool
в обычной ветке продолжай обычный workflow
без подмены профиля или транспорта. Не повторяй вопрос без новых существенных
фактов или конкретного оставшегося пробела.

## Перед остановкой из-за блокировки Goal

Применяет `IG-GOAL-04/07`; этот маршрут имеет приоритет над обычными условиями
выше. До остановки или запроса вмешательства пользователя из-за препятствия
прочитай actual current profile.
Подтверждённая ведущая Astra сама проверяет предпосылки остановки и готовит
вывод; отдельного Консультанта не вызывает. Для остальных моделей, включая
unknown profile, обязательный запрос workflow к Консультанту не зависит от
кажущейся очевидности нехватки доступа, разрешения или внешнего сбоя.
Strategic Explainer не используется для этого разбора или его переписывания.
Single-issue run без Goal сохраняет обычный publication route.

Прочитай доступный `$issue-grinder:consultant` и используй его собственный
контракт запуска. Передай один вопрос: действительно ли самостоятельное
продолжение исчерпано? Укажи current scope и обязательный результат, предполагаемые
причины, наблюдения, уже выполненные попытки, authority boundary и source anchors.
Попроси проверить предпосылки и вернуть доступное действие либо готовый понятный
пользователю отчёт с отдельным объяснением каждой причины: почему она блокирует
обязательный результат, почему агент не может устранить её сам и зачем нужен
заблокированный шаг. Включи checkpoint, непроверенный остаток, влияние, нужное
действие пользователя и observable resume condition. Точные технические
квитанции оставь в отдельном source basis. Не передавай execution/review пакет.

Одна консультация не завершает разбор, пока остаются существенные непроверенные
предположения, перспективные альтернативы или конкретный пробел. Активно обсуждай
разные вопросы и результаты проверок: фиксированного ограничения числа
консультаций нет, цена ложной остановки важнее экономии отдельных обращений.
Новый вопрос и уточнение отправляй по собственному контракту Консультанта;
не повторяй прежний вопрос без нового основания. Итог «нужно разрешение» не
доказывает готовность пути: сначала проверь доступными разрешёнными способами
всю последовательность, затем применяй [единое согласование](autonomy-and-environments.md).

Проверь вывод и source basis по current primary sources и authority. Любое
подтверждённое существенное доступное действие внутри scope отменяет blocker:
выполни его, проверь результат и продолжи delivery. Новые факты после доработки
проходят новый разбор перед следующей остановкой; уточнение того же вопроса
подчиняется follow-up правилам Консультанта. Ведущая Astra выполняет тот же
разбор и обязательную повторную проверку самостоятельно.

Если самостоятельного продолжения нет, покажи проверенный вывод: общий report,
затем отдельные reason answers. Весь комплект проходит reflection до первой
публикации; решение и записи остаются у coordinator. Publication и platform
blocker audit следуют общим правилам; консультация не разрешает ранний
`update_goal(blocked)`.

Недоступный или запрещённый обязательный Консультант означает невыполненную
проверку остановки: сообщи это, сохрани возобновляемое состояние, не подменяй
Консультанта native/Explainer и не объявляй блокировку проверенной. Такой
checkpoint не является принятым blocker fingerprint и не разрешает
`update_goal(blocked)` по числу повторных turns. Не обходи запрет на субагентов.
Неизменный уже проверенный и опубликованный blocker fingerprint не вызывает
новую консультацию или повторный handoff. Изменение существенных фактов,
причин или доступных действий возвращает run к проверке.
